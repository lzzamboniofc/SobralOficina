# Sobral Oficina Automotiva

Site institucional da Sobral Oficina Automotiva.

## Desenvolvimento com Node.js

Requisitos: Node.js 20+ e npm.

```bash
npm install
npm run dev
```

Para gerar uma build local:

```bash
npm run build
npm run preview
```

## GitHub Pages

O projeto mantém o `index.html` e todos os arquivos públicos diretamente na raiz da branch `main`, portanto continua compatível com a configuração do GitHub Pages em **Deploy from a branch → main → /(root)**.

A estrutura visual existente foi preservada. CSS, JavaScript e imagens continuam organizados nas pastas `css/`, `javascript/` e `assets/`.
